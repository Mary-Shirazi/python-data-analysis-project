
# Python Data Analysis & Forecasting Project
**Georgia State University — Computer Information Systems**
**Author: Mary (Mahboobeh) Shirazi**

## Project Overview
This project analyzes business sales data using Python to identify trends, 
generate forecasts, and support data-driven decision making.

## Skills Demonstrated
- Data analysis with pandas
- Data visualization with matplotlib
- Forecasting using statistical metrics (MSE, RMSE)
- Automated reporting with loops and functions

## Tools & Libraries
Python, pandas, matplotlib, numpy

## Files
- `analysis.py` — Main analysis and forecasting script
- `sales_data.csv` — Sample business dataset
