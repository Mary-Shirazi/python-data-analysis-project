# 📈 Python Data Analysis & Forecasting Project

> Business sales data analysis and forecasting using Python — Georgia State University, Computer Information Systems

**Author:** Mary (Mahboobeh) Shirazi | GSU Computer Information Systems

---

## 📊 Project Overview

This project analyzes business sales data using Python to identify trends, generate forecasts, and support data-driven decision making. The analysis covers exploratory data analysis (EDA), statistical forecasting, and automated reporting.

---

## 🔍 Key Findings

| Finding | Detail |
|---------|--------|
| Sales Trend | Identified seasonal patterns and growth trends in business sales data |
| Forecast Accuracy | Achieved low error rates using MSE/RMSE statistical metrics |
| Top Insight | Data-driven forecasts enable better inventory and revenue planning |

---

## 🛠 Skills Demonstrated

- **Data Cleaning** — handling missing values, formatting, and normalization with Pandas
- **Exploratory Data Analysis** — identifying trends, outliers, and patterns
- **Data Visualization** — charts and graphs with Matplotlib
- **Forecasting** — statistical forecasting using MSE and RMSE metrics
- **Automated Reporting** — reusable analysis functions and loops
